

Task: make a simple 2D game (top view, scrollable).

Tech: Browser, client-only javascript.

Game name: Heart Ball / Sirsiņbumba. The Latvian name is preferred.

Characters:
- Player character - a round creature with one eye and a big chomping mouth. Controlled via arrows.
- Flowerboss - the enemy boss at the end of the game. Looks like a Flower drawing, with two big leaves, stem, and a flower with petals as the head.

Items:
- Diamonds - need to be collected. Serves as in-game currency.
- Hearts - need be collected. Form a ball around the player's character. Used to fight against enemies.
- Bowties - need to be eaten by the player.

Theme:
- Flowers, grass, brushes, plants.


Upgrades:
 - The player character's color can be upgraded via a payments (spends diamonds).
